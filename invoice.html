🟢 Siap Digunakan
1. Upload Screenshot Invoice

Pilih semua screenshot sekaligus (bisa 30–50 file). Setelah masuk, urutannya bisa diatur.

🖼️
Ketuk untuk pilih gambar
atau tarik & lepas file ke sini
2. Urutkan

Tips: beri nama file berurutan (001, 002, …) lalu tekan Urut Nama File.

3. Buat Dokumen

PDF: 1 screenshot = 1 halaman A4. Word: 4 screenshot per halaman (2×2) siap print.

Catatan:
• Format gambar yang didukung: JPG / PNG / WEBP. (HEIC dari iPhone sebaiknya diubah dulu ke JPG.)
• Gambar otomatis dikecilkan ke maksimal 1600 px supaya proses ringan & file tidak terlalu besar.
• File Word berformat .docx asli, bisa langsung dibuka & di-print dari Microsoft Word / WPS.
